# QLD Agent Finder — platform

Three separate websites + one database, all free to start.

| Folder | What it is | Address |
|---|---|---|
| `site/` | Main public website | qldagentfinder.com.au |
| `admin/` | **Admin portal** (only you) | admin.qldagentfinder.com.au |
| `agents/` | **Agent portal** (agents log in) | agents.qldagentfinder.com.au |
| `supabase/schema.sql` | Database + security rules | (runs inside Supabase) |

**How it fits together**
- A seller fills in a form on the website → it lands in **Admin → Leads**.
- An agent applies on the website → it lands in **Admin → Applications** → you approve → their profile and ranking go live.
- You **assign a lead** to an agent → the agent sees it in their portal and updates the status.
- Agents log in with a **magic link** (no password), edit their profile and upload a photo.
- Security rules stop agents changing their own rating, reviews or verified badge, and stop the public reading any private data.

## Setup — one time (about 30 minutes)

### 1. GitHub
1. Create a free account at github.com.
2. Click **New repository** → name it `qld-agent-finder` → **Private** → Create.
3. Upload this whole folder (drag & drop on the repo page → **Commit changes**).

### 2. Supabase (database)
1. Create a free account at supabase.com → **New project** → region **Sydney**.
2. **SQL Editor → New query** → paste all of `supabase/schema.sql` → **Run**.
3. **Authentication → Users → Add user** → your email + a strong password (tick "Auto confirm").
4. Back in **SQL Editor**, run (with your email):
   ```sql
   insert into public.admins (user_id)
   select id from auth.users where email = 'contact@qldagentfinder.com.au';
   ```
5. **Project Settings → API** → copy the **Project URL** and the **anon public** key.
6. Paste both into **all three** `config.js` files (`site/`, `admin/`, `agents/`) → commit.
7. **Authentication → URL Configuration**
   - Site URL: `https://agents.qldagentfinder.com.au`
   - Redirect URLs: add `https://agents.qldagentfinder.com.au/**` and `https://admin.qldagentfinder.com.au/**`

> The anon key is meant to be public. The security rules in `schema.sql` protect the data.
> Never paste the **service_role** key anywhere in these files.

### 3. Cloudflare Pages (hosting, free + unlimited bandwidth)
1. Create a free account at cloudflare.com → **Add a site** → `qldagentfinder.com.au` → Free plan.
   Cloudflare gives you 2 nameservers → paste them where you bought the domain (replaces the old ones).
2. **Workers & Pages → Create → Pages → Connect to Git** → pick your repo. Create **three** projects:

| Project name | Build command | Build output directory | Custom domain |
|---|---|---|---|
| `qaf-site` | *(leave empty)* | `site` | qldagentfinder.com.au + www |
| `qaf-admin` | *(leave empty)* | `admin` | admin.qldagentfinder.com.au |
| `qaf-agents` | *(leave empty)* | `agents` | agents.qldagentfinder.com.au |

3. In each project → **Custom domains → Set up a custom domain**.
4. Every time you commit to GitHub, all three sites update automatically.

### 4. Test it
- [ ] Submit **List your home** on the website → shows in Admin → Leads
- [ ] Submit **Join as agent** with a second email → shows in Admin → Applications → Approve
- [ ] Agent profile appears on Find Agents + Rankings
- [ ] Assign the lead to that agent → log in at agents.qldagentfinder.com.au with that email → lead is there

## Day-to-day
- **New leads / applications:** open admin.qldagentfinder.com.au (counts show as red badges).
- **Approve an agent:** Applications → Review → check the licence on the QLD register → **Approve & verify**.
- **Edit rankings data:** Agents → Edit → rating, reviews, sales, days on market.
- **Hide an agent:** set status to `hidden`.
- **Export leads:** Leads → Download CSV.

## Demo mode
If `config.js` is empty, the main site runs with the 12 **demo** agents in `site/data.js` and forms don't save.
Once Supabase is connected, only real approved agents show. You can then delete the demo list from `data.js`.
